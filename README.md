# สกต.กทม. — ระบบบันทึกการเดินทางและการอนุมัติเบิกค่าใช้จ่าย
### สหกรณ์การเกษตรเพื่อการตลาดลูกค้า ธ.ก.ส. กรุงเทพมหานคร จำกัด (SKTbkk)
**ระบบบริหารงานบนเว็บ:** [https://sktbkk.seikouedu.com/travel/](https://sktbkk.seikouedu.com/travel/)

---

## 📌 บทนำและภาพรวมระบบ
ระบบบันทึกการเดินทางและเบิกจ่ายค่าใช้จ่ายในการปฏิบัติงานนอกสถานที่ พัฒนาขึ้นสำหรับ **สกต.กทม.** เพื่อยกระดับความโปร่งใส ความถูกต้อง และประสิทธิภาพในการบริหารงบประมาณค่าพาหนะ โดยมีจุดเด่นคือการตรวจสอบพิกัดดาวเทียม (GPS Geotag) จากรูปถ่ายจริงด้วยระบบ AI พร้อมระบบคำนวณเงินค่าพาหนะและระบบการอนุมัติแบบครบวงจร

---

## 🚀 ฟังก์ชันหลักของระบบ (Key Features)

### 1. การบันทึกการเดินทางและพิกัดดาวเทียม (GPS & AI Verification)
* บังคับดึงพิกัดดาวเทียมจริงจาก Metadata รูปถ่ายหน้าร้าน/จุดจำหน่าย ป้องกันการปักหมุดเอง
* ระบบ AI ตรวจจับชื่อร้านค้าและสถานที่ใกล้เคียงอัตโนมัติ
* แสดงเส้นทางแบบ Interactive Polyline ผ่าน Leaflet Map (OpenStreetMap)

### 2. การคำนวณเบิกค่าใช้จ่ายตามมติคณะกรรมการ สกต.กทม.
* **รูปแบบที่ 1 (คิดตามระยะทางจริง):**
  * ค่าน้ำมันเชื้อเพลิง: **4.00 บาท / กิโลเมตร**
  * ค่าสึกหรอยานพาหนะ: **1.00 บาท / กิโลเมตร**
  * รวมอัตราเบิกจ่าย: **5.00 บาท / กิโลเมตร**
* **รูปแบบที่ 2 (เหมาจ่ายตามโซน):**
  * โซนกรุงเทพฯ ชั้นใน: **300.00 บาท / วัน**
  * โซนปริมณฑล: **500.00 บาท / วัน**
  * โซนต่างจังหวัด: **1,200.00 บาท / วัน**

### 3. ศูนย์พิจารณาอนุมัติคำขอเบิกค่าใช้จ่าย (`approvals.php`)
* แดชบอร์ดสรุปยอดเงินรออนุมัติ ยอดเงินอนุมัติแล้ว และยอดปฏิเสธ
* ระบบตรวจสอบภาพถ่ายและพิกัดแผนที่ก่อนกดอนุมัติ
* ระบบลงบัญชีค่าใช้จ่ายส่วนกลางอัตโนมัติเมื่อกดอนุมัติ

### 4. ใบสำคัญจ่ายและใบเบิกทางการพร้อมพิมพ์ A4 (`print_voucher.php`)
* แบบฟอร์มทางการตามระเบียบสหกรณ์ พร้อมสั่งพิมพ์ลงกระดาษ A4
* สรุปรายการพิกัด GPS, การคำนวณเงิน และช่องลงนาม 3 ฝ่าย (ผู้ขอเบิก, ผู้ตรวจสอบ, ผู้อนุมัติจ่าย)

### 5. โหมดทดสอบระบบข้ามการล็อกอิน (`test_login.php`)
* อำนวยความสะดวกในช่วงทดสอบระบบ ไม่ต้องพิมพ์รหัสผ่านซ้ำๆ
* คลิกเพียงครั้งเดียว ระบบจะตั้งค่าสิทธิ์เป็น **Admin / ผู้จัดการ สกต.กทม.** และเข้าใช้งานได้ทันที

## 🛠️ วิธีการนำขึ้น Web Server จริง (`sktbkk.seikouedu.com`)

   * `approvals.php`
   * `print_voucher.php`
   * `test_login.php`
2. **การทดสอบระบบ (Bypass Login):**
   * เปิดลิงก์: `https://sktbkk.seikouedu.com/travel/test_login.php`
   * ระบบจะพาท่านเข้าสู่หน้าจอทำงานในฐานะ **Admin** ได้ทันทีโดยไม่ต้องผ่านหน้าล็อกอิน

   * นำเข้าไฟล์ `mockup_travel_data.sql` ผ่านทาง phpMyAdmin ของโฮสติ้ง
